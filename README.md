# Design systém šachových artefaktů

Specifikace pro interaktivní šachové artefakty (React / HTML) — zahájení, pasti, koncovky, úlohy a nástroje typu analyzátor. Vše česky.

Aktuální verze je vždy v souboru **`design-system-sachovych-artefaktu.md`**. Číslo verze je v jeho nadpisu a v git tagu.

| Tag | Hlavní obsah verze |
|-|-|
| `v6` | plynulý pohyb figur povinný všude, dvoufázový skok na vzdálený tah, identita figur z FEN/PGN/enginu, vanilla JS nástroje |
| `v5` | start z FEN, proměna, vedlejší varianty, vrstvy zvýraznění, režim úlohy, série, patička s verzí |

Starší verze: GitHub → *Tags*, nebo `git show v5:design-system-sachovych-artefaktu.md`.
Co se změnilo: `git diff v5 v6` (na GitHubu *Compare* `v5...v6`).
